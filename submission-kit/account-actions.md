# Account Actions

These cannot be completed by local files alone because they require your authenticated accounts.

## GitHub

Create a public repository and push this folder. Paste the repo URL into `SUBMISSION.md` and `submission-kit/celo-builders-payload.template.json`.

## Public Demo

Deploy the app to Vercel, Netlify, Fly, Railway, or another public host. Paste the public URL into `SUBMISSION.md`, `SOCIAL_POST.md`, and the Celo Builders payload.

## X/Twitter

Publish one post from `SOCIAL_POST.md`. It must be public and tag:

```text
@CeloDevs @Celo
```

Copy the public post URL. Celo Builders requires this as `socialLink`.

## Celo Builders

Submit to hackathon slug:

```text
celo-onchain-agents
```

Use only this track for now:

```json
["best-agent"]
```

Publish only after the draft shows the GitHub URL, demo URL, social link, contract address, and `celo-sepolia`.

## Optional But Helpful

- Complete Self Agent ID, or capture the unsupported-region/device screenshot if blocked.
- Add ERC-8004 / 8004scan only if the agent is actually registered and visible.
